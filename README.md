# streets-of-simcity-custom-scenarios
Streets of SimCity Custom Scenarios

This is a repository for the scenarios I have made for the 1997 Maxis game Streets of SimCity.  In the early 2000s, I had started reverse engineering the scenario format for this game, and got maybe halfway there, and moved on to other things such as college.  Once COVID hit, @CahootsMalone separately deciphered the scenario format, which was immensely useful to help me complete the ideas I had had decades prior.  Since then, I have made a few more scenarios as well, and want to share them.
Stay tuned for uploads of scenarios and associated cities and information!
